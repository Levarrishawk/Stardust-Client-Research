# Skeletal material texture defaults

The object-root creature reader accepts explicit `loadMaterialDefaults` only with owned geometry. It follows each original PSDT shader name, decodes SSHT or CSHD through the existing authored-default query, then owns named effect and DDS dependencies in the same source cache. Every external path is resolved once. Source resource/byte and decoded-pixel budgets apply. Missing/masked shader, effect or texture rejects the complete load. Palette records remain available; base texture-only mode does not implicitly resolve or translate palette resources. MGN texture renderer bindings remain descriptors.

For the pinned original male human plus selected idle, the closure is32 sources/4,668,368 bytes: four CSHD0001 materials, three effects and ten DDS textures/80 declared mips. The face CNRM authored age default selects `wrinkles_m_s01_cn.dds`, replacing the inline s04 reference. Original MAIN textures are body/head/face/mouth. This closes parser/dependency acceptance for this bounded slice, not full material customization.

Godot opt-in `-CreatureMaterialDefaults` requires `-Creature`. CPU loading stays on the worker; one owned result transfers to the main thread. The preview uploads all decoded texture mips, shares four material resources across five surfaces, and retains them during pose updates. An opaque single-pass MAIN candidate, one named MAIN binding and MAIN UV0 are required. Partial mip chains and premultiplied MAIN RGB reject. The rendering policy is unshaded MAIN RGB using the existing color-space convention. It does not execute the original effect capability branch, normal/specular maps, palette factors, generated face compositor, clothing or active occlusion. The visibly pale authored textures are expected before palette shading.

The native `--skeletal-materials` probe uses the same pinned object/SAT arguments as the existing descriptor probe. It emits compact source/material/mip identities; `verify_skeletal_descriptors.py` now independently checks original PSDT shader membership, CSHD fields/default choices, SSHT effect/texture/coordinate bindings and every Pillow-decoded mip. Geometry and sampled animation oracles continue to run. Malformed option combinations reject before lookup; missing dependencies and source count exhaustion reject. Headless, cancellation, GPU texture/geometry readback,480 animation updates and play/focus/pause/seek gates pass. Capture was inspected.
