# Borrowed terrain session pause and stop

[TerrainOfflineSessionController](../../SWG-Godot-Client/poc/Stardust.Core/Session/TerrainOfflineSessionController.cs) borrows the actual point/manual terrain driver. Constructor: `TerrainOfflineSessionController(SceneWorldTerrainPointTargetDriver driver, int maximumUpdates, long stepMicroseconds = 10000)`. Count is1..6000, step1,000..100,000 microseconds. Require unadvanced completed/attempted zero, actual healthy inner result/clock and exact actual driver-state reference. Capture initial driver pause intent. Hidden driver update cap and configured step are caller construction contracts; this wrapper cannot prove them through the frozen public API. Caller must supply enough driver capacity, the same step and serialized sole ownership.

Owner-guarded `State` exposes immutable `TerrainOfflineSessionState(CompletedUpdates, Paused, StopRequested, Stopped, IsFaulted, FaultType, DriverResult)`. DriverResult is the actual point-driver state, whose DriverResult is the actual terrain result. CompletedUpdates is actual successful completed driver count, not reserved frame slots or attempted ticks. Historical state remains owned and readable after Dispose.

`SetPaused(bool paused)` and `RequestStop()` change only owned intent. They leave borrowed driver/target/manual/row/clock unchanged; repeated equal intent is idempotent. Actual target/manual/speed setters may run outside controller busy between ticks at unchanged current clock/count. Pause belongs to the controller after construction; independently setting driver pause is unsupported. No external driver Advance/reset/dispose is allowed. Before each operation, detect changed completed/attempted counts or clock and latch terminal `ExternalDriverProgress` with actual prefix. A same-count externally unhealthy/disposed driver latches `ExternalDriverUnhealthy` before borrowed mutation.

`AdvanceNext(long currentClock, long nextClock, CancellationToken token = default)` admits owner/open/nonterminal/token/current clock/count, exact next=current+configured step and signed64 overflow before borrowed mutation. Wrong valid-range deltas such as9ms under10ms step reject without changing owned/borrowed identities. Caller step mismatch can still make the frozen driver reject; configuration is not exposed, and no arbitrary-step probing proves it.

Normal tick applies owned pause through actual driver.SetPaused at the exact current clock, then invokes actual driver.AdvanceNext once. Paused ticks remain active grounded zero ticks with target/manual intent retained. On requested stop or the final allowed update, first unpause, then ClearTarget to clear both manual and point intent, then invoke the same one actual tick. Stopped is set only after a successful next-clock single grounded update with actual zero speed, Idle and no target/manual. Automatic final stop sets StopRequested and Paused=false. It consumes the final ordinary update; no extra stop tick, fictitious completed count, capacity refund or rearm occurs.

The mutation boundary begins when SetPaused is attempted. Subsequent failure/cancellation latches terminal state containing actual borrowed point result/count, even if that attempted setter rejected before effects. Completed mutations/publications survive; no rollback or retry. A terrain-edge failure can retain attempted1/completed0; a hidden cap mismatch can retain one completed update without claiming Stopped. Initial token/clock preflight rejects unchanged. Reentry, narrow cancellation races and rare allocation failures are source-inspected without callback hooks. State diagnostics at a caught post-mutation failure describe actual prefix, not promised completion.

Stopped/faulted sessions reject future ticks and intent setters. `Dispose` is idempotent on owner thread, drops only its borrowed reference and preserves historical State; it does not stop/dispose the driver or close world/store. Call RequestStop and complete its actual stop tick before disposal if a zero borrowed motion row is required. Original input/gameplay/gait/physics/camera/cadence remains Unknown; this is explicit modern offline lifecycle.
