# Complete CREO view 3 baseline

The engine-neutral `CreatureView3BaselineCodec` decodes all eighteen registered fields and exposes the accepted six-field `CreatureView3ScalarState`. The application envelope uses numeric tag `0x4352454F`, view 3, a 23-byte outer header, and a two-byte declared field count. The server's 27-byte header includes four transport bytes. Declared counts are retained and do not control field traversal. The complete body must be consumed exactly.

All numeric fields use little endian. In order: F32 complexity; StringId (extended byte string file, U32 spacer, extended byte string key); U32-counted raw UTF-16 units; U32 volume; extended customization byte string; component snapshot (U32 count, U32 counter, S32 keys); U32 options, use count, condition damage, maximum condition; U8 visibility, posture, rank; U64 link; F32 height; U32 shock bits; U64 states; wounds snapshot (U32 count, U32 counter, S32 entries).

Byte strings use a U16 byte count, or `FFFF` followed by U32 count. Encoding preserves the prefix choice, high bytes, embedded zeroes, float bits, unpaired UTF-16 units, counters and collection order. Owned arrays and read-only views prevent callers from modifying snapshots. The decoder does not interpret strings or bind objects to a world.

Evidence and confidence: [replication schema](REPLICATION_SCHEMA_MAP.md) records the complete CREO:3 order and RTTI registration (Confirmed). Customization readers `00641030/00641180` use extended byte strings. Component snapshots `00642B80/00642F00` are `AutoDeltaSet<int>` with four-byte keys; eight-byte readers `006421A0/006423E0` concern a separate cached-network-ID vector (Confirmed). Snapshot traversal `0118B740` iterates registered fields despite declared count. Raw UTF-16 length ownership is documented in [login state](LOGIN_AND_ZONE_STATE_MACHINE.md).

Server correlation: sibling Core3 `MMOCoreORB/src/server/zone/packets/creature/CreatureObjectMessage3.h`, constructor, appends fields 11–17 to `tangible/TangibleObjectMessage3.h`, constructor, fields 0–10. `scene/variables/AutoDeltaSet.h::insertToMessage` emits count, counter and HashSet keys. Server keys are unique with unspecified iteration order. Original duplicate normalization remains Unknown; this modern codec preserves raw entries, including synthetic duplicates, without claiming original set behavior.

Modern failure policy rejects nonfinite floats, wrong schema/opcode, truncation, mismatched envelope size, trailing bytes and configured budget violations. Limits bound envelope payload, each string, Unicode units, each collection and aggregate logical retained bytes. Aggregate accounting is 81 fixed bytes plus string bytes, twice Unicode units, and four times collection entries. It excludes CLR overhead, wire prefixes and temporary envelope copies; it is not a total heap cap. Finite negative/nonunit height and signed zero are retained.

Independent synthetic verification compares native encoded messages at declared counts 0 and 65535 against Python `struct` packing and checks every exported field. This establishes bounded implementation behavior; it adds no original-runtime or live-server coverage claim. Full baseline-to-world state binding and set update semantics remain deferred.
