# Explicit authored and received movement input join

The [72-case native join](../../SWG-Godot-Client/poc/round47-tests/Integration/MovementInputJoinProgram.cs) uses actual Core APIs: [authored selection](SHARED_CREATURE_AUTHORED_MOVEMENT_INPUT_CONTRACT.md) and [received world inspection](SCENE_WORLD_RECEIVED_CREATURE_MOVEMENT_INPUT_CONTRACT.md). These inputs have independent origins; this join defines no original arbitration, default seed or modifier formula.

One pinned original human necessary-parent chain supplies five authored inputs. The existing configured overlay and root/configuration SHA gates load it once; its raw values and generated receipts remain private. An independent source-byte oracle reconstructs the exact authored bits and winning source path. The synthetic received world uses literal staged scalar messages from the accepted six-state partial host sequence, relabelled to object1. Its source provenance is independently modeled from literal bytes.

For each pending/finalized phase, six states, fields7/11 and three supplied normalized planar directions, the native result preserves all ten nullable F32 slots and their exact source provenance. Generic finite inspection does not combine acceleration/base/modifier/turn fields. An explicit modern received-speed check uses only the requested field, finalized context, finite raw value and nonnegative value. It supplies no authored fallback. Separately, the caller explicitly chooses authored Speed0 or Speed1 under a named nonnegative policy and the accepted pure planar adapter. The two outputs can disagree or only one can exist.

The independent [peer](../../SWG-Godot-Client/poc/round47-tests/Integration/movement_input_join_peer.py) verifies72 rows, including36 missing received-speed cases and36 pending non-operational cases. Authored selection can remain determinate while the received speed is missing. AuthoredPhaseEligible means only the captured finalized phase; it does not prove the existing motion driver's other prerequisites or authorize applying a velocity. Direction products are checked as exact binary32 outputs. Signed-zero/nonfinite raw state is not treated as absence.

Both ordinary and finalized-only readers are exercised. Pure reads and authored selection preserve exact received source currency and state/journal accounting. World close invalidates the reader's lease and clears partial state/journal. The state-only synthetic worlds do not request original scene resources; the separate [original-resource preview](SCENE_WORLD_RECEIVED_MOVEMENT_PREVIEW_CONTRACT.md) verifies that host boundary.

**Observation:** native and independently derived original-authored/literal-received receipts agree. **Interpretation:** the replacement can expose and explicitly select these two sources without silently seeding or merging them. **Confidence:** Confirmed for the documented modern selection policy; original effective runtime precedence remains Unknown. **Next:** trace one original speed writer/arbitration or introduce an explicitly selected modern locomotion policy, keeping its provenance separate.

Reproduce by generating a private fixture from the pinned movement oracle with movement_input_join_peer.py, building MovementInputJoin.csproj using the sources-cleared cached NuGet configuration, running its DLL with asset-root/configuration/fixture/output arguments, and verifying the exact output against the same oracle. One lead build initially lacked a compiler-recognized null guard; an explicit coalescing throw fixed CS8602. The final build has zero warnings/errors.
