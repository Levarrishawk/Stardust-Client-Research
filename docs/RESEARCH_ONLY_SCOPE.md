# Research-only repository boundary

Effective October 14, 2026, this repository contains research, specifications,
curated registries, dated evidence reports and standalone analysis tools.
The Core/Godot implementation, historical test projects, build/export tooling,
preview launchers and verifiers that depend on that prototype live in
[SWG-Godot-Client](../../SWG-Godot-Client/README.md).

Dated implementation checkpoints and sessions are retained as evidence of
compatibility probes. Their results describe the tested version and do not
constitute current development authorization or new validation. Historical
commands mentioning `poc/` or removed tools must be run from SWG-Godot-Client;
Markdown links now point to the relocated files. Both sibling checkouts are
needed to resolve those cross-repository evidence links.

Original executable observations, protocol/asset contracts, all four curated
CSV registries and unrelated NGE compatibility research are preserved.
Private evidence and inputs remain ignored. No executable reanalysis, original
execution, live-server contact or publication was performed for this cleanup.

Resume research by selecting a bounded unresolved question from the relevant
contract and following the repository evidence rules. Implementation changes
belong in the separate client repository.
