# Research-only documentation scope

This repository contains independently authored reverse-engineering research,
compatibility specifications, evidence reports, canonical registries and analysis
tools. Client source, engine integration, launchers and build/export work are
outside its scope. No engine is selected or prescribed by the current research
entry points.

## Historical evidence

Dated prototype and source-client reports remain because they record useful
compatibility probes, observations, contradictions and limitations. Their results
apply to the tested inputs and versions, not to a complete replacement client.
Past development schedules and authorizations are historical only.

The October 14 documentation cleanup removes engine branding from public Markdown.
Historical engine references use the descriptive term "prototype host". That term
is not a renamed API, binary or product. Engine-specific external links, identifiers
and command/code examples are omitted rather than replaced with invented working
paths or commands. Local evidence filenames and links use neutral terminology.
Dates, observed counts, addresses, confidence labels and original compatibility
limitations remain evidence; the original pre-edit documents are backed up in
ignored local-private/research-documentation-cleanup storage.

Historical references to removed implementation files are provenance descriptions,
not runnable instructions within this repository. Consult the separate implementation
record when reproducing those old experiments. Standalone retained research tools
continue to use their documented input identities and paths.

## Current measurements

Use [current research status](../ANALYSIS_STATUS.md) for the latest registry counts,
the last formal weighted coverage estimate and explicit remaining questions.
Behavioral coverage, implementation-decision research readiness, function
classification and packet inventory coverage have different denominators.
Documentation cleanup does not advance any of those measures.
