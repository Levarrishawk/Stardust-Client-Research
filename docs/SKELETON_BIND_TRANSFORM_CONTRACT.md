# Skeleton bind transforms

The engine-neutral `SkeletonBindPoseBuilder` implements the recovered scalar-first local rotation RPST*BPRO*RPRE, translation BPTR, rigid transpose inverse and legacy product `localInverse * parentOrExternal`. JROR is retained by the decoder and unused here, matching the inspected routine. “Inverse bind” remains a strongly inferred behavioral label; field order and product are Confirmed by executable evidence.

Matrices returned as `System.Numerics.Matrix4x4` are transposes of the legacy row-major3x4 column-vector matrices. Therefore hierarchical inverse composition is **parent/external row matrix * local inverse row matrix**. Local quaternion products retain the recovered order. The builder uses float arithmetic without renormalizing or changing quaternion signs; it preserves the converter's positive-identity shortcut when W+1.0000000272452012e-27>=1. The original constant at015EAB28 is rawD2749E12 (little endian), while015DC6F8 is1. This is approximate numerical compatibility, not bit-identical x87 execution.

Inputs are bounded to2,048 joints, ordered parents/one root for nonempty data, finite near-unit rotations and finite translations within1e6. External/computed transforms must have affine shape, finite bounded translation and right-handed rigidity within the declared0.002 tolerance. Scaling/reflection rejects. Zero joints are supported. Returned lists own matrix values. No animation controller or renderer skeleton is created.

For the bounded original human probe, each of four body levels is built under identity external root. Face level0 is attached using the corresponding body's folded Head inverse transform as its external root. This is an explicit tested bind composition, not a general runtime skeleton LOD fallback policy.
