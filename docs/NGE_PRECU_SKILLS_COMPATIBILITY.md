## Implemented boundary

SD-Src-Client adds `sharedSkillSystem/PrecuSkillCatalog.h` and `PrecuSkillDataTable.h`. The engine-neutral definitions preserve the named fields and authored row/list order. Costs, commands, modifiers, schematic grant/revoke names and filter metadata come from the mounted table. They are not substituted from a base-game progression assumption. In particular the tested Stardust brawler rows have zero point costs.

Catalog replacement is transactional: empty/duplicate names, unknown parents or prerequisite/preclusion references, invalid graph values, negative costs and parent cycles reject the candidate while retaining the existing catalog. Parent navigation and dependency traversal are iterative. Dependency traversal is bounded by visited names and tolerates a cyclic prerequisite graph without recursion or a hang; this is defensive termination, not acceptance of a cyclic gameplay rule.

Selection stores canonical names. Unknown skills and non-profession profession selections are rejected; the ten monitor slots reject out-of-range indexes and unknown names, allow explicit clearing and revalidate on catalog replacement. Viewing an unowned skill is valid presentation. The catalog and selection layer sends no packets, grants no ownership and changes no server state.

The DataTable adapter checks every required column's basic type before accessing cells. It preserves mission/stat strings and the raw ENDER integer. Neither original NGE `SkillObject` memory layout nor replication enums are changed.
