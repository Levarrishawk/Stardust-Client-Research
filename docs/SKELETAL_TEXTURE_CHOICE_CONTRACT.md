# Owned skeletal texture choices

`loadTextureChoices` requires owned material defaults. The opt-in reader loads all serialized CSHD choice paths through the existing shared source/decode caches, with the existing64-texture and128 MiB decoded-pixel ceilings. Strict default loading still reads only authored selections. Missing/masked choice sources fail this complete-closure mode explicitly.

`SkeletalTextureChoices.Apply` accepts exactly the case-sensitive name/Boolean namespace keys of all texture controls and owns a snapshot. Per-operation selections clamp to0..ChoiceCount-1; authored index/tag/requested/clamped/path provenance remains explicit. Bindings derive from serialized inline references in authored operation order. Absent target tags never create bindings. Selected bound textures must already be owned. Original material/effect/texture dictionaries and metadata remain unchanged; returned selection owns derived references. Cancellation precedes publication. This is inspection/selection state, not evidence of original default lifecycle.

Original selected human face CSHD has private `index_age`, four choices and CNRM tag1129206349; other three materials have no texture controls. All choices are original wrinkles_m_s01 throughs04 compressed normal maps. Original object/SAT/idle/material closure is35 sources/5,717,408 bytes, adding three349,680-byte DDS sources to the prior32-source closure. Independent raw CSHD reference/metadata/path audits agree for six selections(INT_MIN,0,1,2,3,INT_MAX); all decoded mip hashes agree. Original application0077BEE0 and the earlier [query contract](AUTHORED_CUSTOMIZATION_TEXTURE_CONTRACT.md) establish per-operation clamping and target membership.
