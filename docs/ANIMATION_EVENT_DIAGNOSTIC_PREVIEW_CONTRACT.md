# Animation event diagnostic preview contract

R3-RUNTIME-01 delivers the [modern playback bridge](ANIMATION_EVENT_PLAYBACK_CONTRACT.md) into a bounded diagnostic log and an original walk/run geometry preview. It does not map names to effects/audio, apply LOCT translation, alter the accepted-movement scene clock, execute the animation graph or claim original event scheduling. Original scheduling and compiled LIT remain **UNKNOWN**.

## Bounded engine-neutral sink

`new AnimationEventDiagnosticLog(playback, capacity = 128)` binds to exactly one playback owner. Capacity is1..4096 and allocates one fixed ring. `Deliver(batch)` requires a nonempty batch accepted by `playback.IsCurrent(batch)`, rejecting foreign owners, stale generations and empty batches. The preview skips empty batches. `DeliveredTotal` counts all accepted occurrences over the sink lifetime; `GenerationDeliveredTotal` counts accepted occurrences in the current synchronized playback generation. These are diagnostic delivery totals, not all generated events if the caller discards batches.

Order is strictly ascending `(Cycle, Frame, GroupIndex, OccurrenceIndex)`. A single last-delivered frontier rejects replay and backward delivery; each proposed batch is checked completely against that frontier and internally before ring/totals change. This ordering matches the cursor's terminal-old-cycle before next-cycle frame0 policy. Identical names/frames retain distinct authored indices and are accepted. This policy deliberately does not support arbitrary historical reordering: if a caller delivers a later batch first, earlier batches subsequently reject. No unbounded identity set is retained.

Each `Recent` access returns an owned read-only oldest-to-newest snapshot of at most Capacity immutable `AnimationEventDiagnosticRecord` values: lifetime Sequence, owner-local Generation and Occurrence. Ring overwrite does not change retained snapshots. Consumers associate records with the bound sink/playback; Generation is not a globally unique owner ID.

`ClearRecent()` clears display history, retaining generation/frontier and both totals. It cannot rearm already-delivered occurrences. `SynchronizeGeneration()` is a no-op for an unchanged generation; on playback restart/reset/replacement it clears history/frontier and the per-generation count while retaining lifetime totals. Delivery of a valid nonempty current-generation batch also synchronizes automatically. Stale/foreign/empty/replayed delivery never changes diagnostic state, including during a pending generation switch. Counter exhaustion rejects before mutation. All access is single-owner/serialized; no dispatch callbacks or disposal resources are introduced.

## Original diagnostic adapter

`AnimationEventDiagnosticPreview` owns background loading, frame updates, focus notification, controls and teardown in its own Node. [Main partial builder](../../SWG-Godot-Client/poc/Stardust.Godot/Main.AnimationEvents.cs) creates it; the only shared Main edit is the `--animation-event-preview` dispatch branch immediately before `--asset-creature`.

Read-only original input: pinned human object -> SAT -> existing skeleton/mesh/bind geometry and prepared idle plus explicit walk/run bank. Use the existing [bank profile/routes](SKELETAL_ANIMATION_BANK_CONTRACT.md), [clip identities/messages](COMPRESSED_LOCOMOTION_CONTRACT.md) and configured effective overlay. Config/object/SAT/idle/walk/run pins are validated before publication. CPU background worker closes archive scope before one main-thread result transfer; first-lookup cancellation publishes no geometry. Late result/cancellation after Node exit returns without touching the exited node. Public files contain no original asset bytes.

Default selection is walk. Selecting walk/run replaces the playback clip and creates a new epoch; restart also creates a new epoch. Immediately prime `SkeletalMeshPreview.SetClipFrame(key,0)`, then tick through `SetMovementFrame(key,playback.CurrentFrame,0)`. Priming the same key prevents a zero-time transition from freezing at the previous clip. The diagnostic does not crossfade or translate its mesh root. The existing original pose/geometry adapter remains read-only.

Interactive controls: Walk, Run, Pause/Resume, Restart, Clear history and an Allow playback focus gate. Physical window focus is also required. A frame/cycle/generation/count label and recent authored names/frames show current-generation records only. Pause/focus loss discards elapsed time. Process delta is finite/nonnegative and clamped to0.25 seconds as explicit modern stall policy; excess stall time is discarded. Camera orbit/zoom uses existing preview controls. Geometry uses the existing authored MAIN/UV0 material adapter: four original MAIN bindings/four distinct MAIN images and ten decoded texture upload resources (14,330,528 bytes, including other authored defaults). No new shader, generated face, palette or compiled-LIT policy is introduced.

Exit disables frame publication, cancels/disposes the loader, frees the mesh root/resources, drops playback/log/bundle references and disposes owned environment resources. The Node owns these hooks; no shared Main process/exit/focus hooks are added.

## Run and integrate

[Launcher](../../SWG-Godot-Client/tools/powershell/Invoke-StardustAnimationEventPreview.ps1) takes GodotPath, ArchiveRoot and Configuration. Default or `-Headless` runs a bounded deterministic headless fixture; `-CancelLoad` runs first-lookup cancellation. `-Interactive` starts the visible preview for authorized lead inspection. Separate `-CapturePath <fresh-private.png> -CaptureClip walk|run` starts a hidden bounded GPU capture, holds walk at frame9 or run at frame8 in cycle1 with three current-generation occurrences, waits three rendered frames, verifies the mesh and all texture/mip readbacks, saves the private PNG and quits. It does not combine capture with headless/self-test/cancellation/interactive mode; GPU capture execution remains unrun by this worker. Launcher output logs stay ignored/private, paths with spaces are quoted and bounded fixtures have a45-second deadline. It does not build automatically; use an already built replacement assembly.
