Caller ticks its application/run before ticking the pacer. Selected phase, exactly one client ReadySubmissions and world `Ready` are all required. Client-ready submission with `AwaitingServerReady` does not arm. Each root requires at least400 actual caller milliseconds since arming or the last accepted root. At most one root is queued per Tick. A delayed call cannot emit accumulated steps; its accepted real time becomes the next400 ms gate. Fixed logical stamps describe the candidate movement sequence; delayed scheduling is slower than that sequence and is not proof of elapsed server clock or admission. Caller must independently observe timing/state before claiming controlled-server acceptance. Queued means admitted to the existing transport/pump, not sent, acknowledged, or accepted by the server. Continue application Tick to perform sends.

`ZonePendingMessages` is checked before driver advancement. Real pending-message backpressure preserves the exact issued pose, counter, stamp and last accepted time. Retained unacknowledged packets already in the reliable window do not necessarily constitute pending-message backpressure. Existing run admission is repeated after movement; an unexpected false result there stops rather than retrying an already advanced pose. Under the intended same-thread owner sequence there is no intervening callback between pending check and admission; this invariant is source-inspected, not fault-injected.

Three admitted roots cap the sequence; subsequent healthy Tick returns Completed without movement. Dispose remains required and completion does not automatically disconnect. Cancellation, close/disconnect/fault, changed selection/generation, any observed full-transform correction status, foreign publication, changed incarnation, containment, unsupported placement or lost readiness stops permanently. Historical accepted motion/prefix remains intact; there is no reset/resume or reconciliation after a correction. A canceled Tick returns Stopped rather than throwing. The engine adapter disposes the pacer before application finalization.
