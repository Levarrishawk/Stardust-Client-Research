# Scene resource option preservation

Focused scenarios (external historical reference) exercise the public `SceneObjectResourceRequest` and actual `SceneObjectResourceInitializer` loader callback. This regression milestone changes no production API, world, renderer or source reader. Its own runner accepts root/config/catalog/literal-fixtures paths.

## Preserved fields and ownership

The accepted request reconstructs static options with `MaterialPolicy`, explicit `SwitchTextureFrame` path/pin/index, graph resource/source/depth/edge limits, `MaximumDecodedBytes`, and optional `SwitchFrames`. All-frame policy retains its total mip/pending ceilings, nullable bundle limits, frame/source/source-byte/decoded/mip/shader ceilings, nullable DDS limits, dimension/input/decoded ceilings and terminal-tail flag. Null defaults remain null at the policy/bundle/DDS boundaries; default graph/scalar values remain the established constructor values. The selected static pin's authored case is retained.

The request owns distinct snapshot/create/option/graph/selection/policy/bundle-limit/DDS-limit records when present. Record inputs are immutable; `with` creates another value. Creature options own distinct idle/movement selections, readonly motion maps and copied explicit child-route arrays. Mutable source routes/banks/face-value dictionaries are cleared or overwritten after construction without changing request/callback projections. Creature table paths normalize and clip pins uppercase under existing constructors. The sealed get-only face policy and its private readonly value dictionary are safely shared across option copies; this regression does not require unnecessary face-policy cloning or infer original face defaults.

Synthetic option fixtures deliberately use unusual scalar ceilings, frame indices/pin case, route indices and face values to expose dropped/reset fields. They claim option acceptance/preservation, not that those settings or synthetic animation paths load a real asset. Two creature fixtures cover default albedo/limits and nondefault albedo, limits, routes, face budget, signed values and both raw factory flags. Eight static fixtures cover neutral/complete defaults, selected defaults/nondefaults, all-frame null limits, null DDS limits, full nondefault nested DDS policy and exact original ceilings.

Every fixture traverses a public request and an actual initializer callback. Literal Python-authored expectations compare explicit field projections at both boundaries, without deriving expected values from reflected constructor metadata. The initializer retains the already-owned request; it does not copy options again at Start. Controlled canceled tasks prove capacity remains charged until Poll consumes completion.

The test reconstructs the earlier omitted-`SwitchFrames` option shape and proves it differs from the requested all-frame projection. More directly, omitting this argument in the actual request copy makes the all-frame ownership/projection cases fail before original loading. No production source is mutated to demonstrate the regression.

## Rejection and completion responsibilities

Null options, both catalog/option recipe mismatches and an unsupported catalog recipe reject through public constructors. The base option type is abstract with a private-protected constructor and the two supported implementations are sealed; an unsupported option subclass cannot be supplied through the public API. Metadata inspection confirms that API restriction but does not claim execution coverage of the internal unreachable fallback branch.

A worker-owned configured overlay prepares the pinned terminal all-frame resource through the actual initializer callback, using the copied exact options. It reads34 unique sources, closes archives and clears borrowed source arrays before completing. Owner Poll transfers the matching resource once. Default27-source completion and an independently loaded altered-policy completion are replayed from private owned source snapshots. A test-only internal wrapper around a public record copy removes the bundle for the malformed completion case; reflection is confined to this fixture construction, not expected-field derivation or product code.

The existing completion validator rejects missing-bundle/default/altered-policy resources. The initializer invokes that validator during Poll, converts rejection into Faulted with no resources and releases the finished job. Separate controlled tests prove current cancellation produces Canceled, containment or registry closure produces Stale, and both suppress late successful resources. Closing the initializer immediately removes ownership but retains unfinished-job charge until its disposal continuation drains; both late success and late fault are observed with zero outstanding jobs. Closed Poll rejects and repeated Dispose remains safe. These are modern ownership policies, not recovered original scheduling behavior.
