# Owned integer offline frame planner

[TerrainOfflineFrameClock](../poc/Stardust.Core/Session/TerrainOfflineFrameClock.cs) reserves fixed-step scheduling slots from caller-supplied elapsed integer microseconds. Constructor: `TerrainOfflineFrameClock(long stepMicroseconds = 10000, int maxStepsPerFrame = 8, int maximumReservedSteps = 2000, long maximumFrameMicroseconds = 250000, CancellationToken token = default)`. Step is1,000..100,000 microseconds, per-frame slots1..32, total slots1..6000, frame input bound1..250,000 microseconds. Default total2000 does not implicitly change the [separate terrain session budget](TERRAIN_OFFLINE_SESSION_BUDGET_CONTRACT.md).

`AdvanceFrame(long elapsedMicroseconds, CancellationToken token = default)` admits elapsed0..configured maximum. Add elapsed to prior fractional remainder using checked signed64 arithmetic. Divide available time by step to obtain whole steps due. Reserve `min(due, maxStepsPerFrame, remainingTotalCapacity)`. Drop all other whole steps explicitly, retaining available modulo step as remainder. Per-frame dropped time is `(due-reserved)*step`; cumulative dropped time adds it with checked arithmetic. At total capacity, return zero Steps, continue carrying fractional time and dropping any whole steps. No reset/refund/rearm or host callback exists.

`AdvanceFrame` and owner-guarded `State` return immutable `TerrainOfflineFrameReceipt(Steps, StepMicroseconds, TotalReservedSteps, RemainderMicroseconds, DroppedMicroseconds, TotalDroppedMicroseconds, Exhausted)`. Steps is this frame's reserved slots; DroppedMicroseconds is this frame's drop; TotalReservedSteps and TotalDroppedMicroseconds are cumulative. `Exhausted` is also an owner-guarded clock property. Initial state has zero counts/time and Exhausted=false. Each valid call, including zero elapsed, publishes a new immutable receipt. Prior receipts remain unchanged.

Reserved slots are **issued scheduling capacity**, not completed movement, animation, camera or presentation. A correction-only slot, failed host callback or unused final slot remains reserved. Caller must count completed core work separately and pass each consumed ordinary step to existing exact-clock/per-step components. Corrections cannot refund clock capacity. This planner owns no engine, row, actor, network, event history or driver; it makes no accepted-position/provenance claim. Finite floating-second conversion, focus/pause sampling and clamping larger render gaps belong to the engine caller. Time clipped before this planner is caller-dropped time, distinct from the planner's explicit whole-step dropped total.

Owner/non-reentry/open/token/range/arithmetic and immutable-candidate allocation precede state replacement; cancellation is rechecked before replacement. Invalid negative/oversized/long.MaxValue inputs and canceled requests retain exact state identity. All additions/products that could overflow use checked arithmetic. Cumulative dropped-time overflow remains source-inspected because bounded frame inputs would require impractically many calls to reach signed64 exhaustion; no private-state injection manufactures execution coverage. Reentry and post-check cancellation races are likewise source-inspected. `Dispose` is terminal/idempotent on owner thread; State and Exhausted retain historical values, further AdvanceFrame rejects. No rollback or implicit retry is introduced.

[Independent Python](../poc/round74-tests/Runtime/verify_frames.py) writes exact integer receipts before native execution. Six cases compare7,759 frames:100Hz through total cap, integer60Hz partitions, varied zero/fractional/250ms late frames with eight-slot drops, fractional carry after a seven-slot cap, one-slot per-frame limit and maximum100ms step/6000-slot capacity. Aggregate across independent cases:12,107 reserved slots and66,240,000 dropped microseconds. Conservation holds exactly: supplied elapsed = reservedSteps*step + totalDropped + remainder.

[Native scenarios](../poc/Stardust.Core.SmokeTests/TerrainOfflineFrameClockScenarios.cs) pass15,724 checks/92 negatives, including configuration/input/token/owner/dispose/historical receipt gates. Simulated caller-completed/skipped counts sum to reserved capacity and never refund it; these are mock completion counts, not actual movement execution. No optional core-driver join is claimed in this worker. One offline build zero warnings/errors; all4404 frozen source paths unchanged, no existing scheduler change or broad default/host/GPU/live/original executable run.
