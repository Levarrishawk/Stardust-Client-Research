The host cases cover success, pre-ready cancellation, minimum-provider failure,

quitting the owning Godot loop.

Controlled movement uses an explicit caller clock and asserted fresh-state

terrain/avatar/gameplay or live disconnect release. Synthetic input is not
physical OS input evidence. The [controlled-server plan](../../../docs/CONTROLLED_SERVER_VALIDATION_PLAN.md)
requires separate operator inputs and explicit authorization before contact.
