# Original-installation client-run verification

This offline join opens `ReplacementLaunchPreparation` from a private JSON profile generated from explicit installation root/configuration and documented human animation choices. `ReplacementClientRun` supplies login, authentication, selected zone, ingress/readiness, movement/corrections and disconnect through the actual injected datagram pump. Godot presents the same selected original human throughout movement. No socket or DNS service is constructed.

Run the consolidated command in [the regression runbook](../../../docs/CLIENT_REGRESSION_RUNBOOK.md), with explicit local tool/cache/installation inputs and a fresh ignored output. The Round88 join is its default native entry. `--gpu` adds a real renderer case; without it GPU is unverified.

Five headless cases cover successful final send, cancellation before ready, minimum terrain failure, synchronous final-send error and cancellable final-send timeout. The optional sixth case renders the successful path. The accepted Round87 independently authored protected peer verifies exact authentication, selection, ready, three local movements, newer/duplicate/older/wrap corrections, deferred bytes and disconnect. Independent archive readers verify preparation, loaded closure and terrain identities; the native profile hash must match the generated profile.

The minimum provider decodes original PTAT and waits for a live scene owner; full procedural terrain readiness remains unproved. CREO1/PLAY gameplay, nearby presentation, arbitrary avatars/customization, original movement timing/prediction and actual server receipt/release remain open. Authored peers and modern input/timing policies establish deterministic offline behavior only. They are not interoperability evidence.

The run owns its adapters and borrows session/pump/world/motion store. Close the run, retire ports and presentation/world, await successful drains, then dispose the motion store, session and launch preparation. Typed send failure and asynchronous drain failure must remain distinct from successful local cleanup.
