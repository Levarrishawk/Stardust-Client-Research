# Offline selected-player movement join

This composition executes the reusable login/selection/scene components, original installation-derived human preparation, modern planar local input, protected outbound full-root movement, inbound authoritative corrections and the same Godot actor. It injects independently authored peers without sockets or DNS. It proves the implemented offline boundaries, not live interoperability, legacy movement cadence, collision or complete terrain readiness.

## Reproduce

Supply absolute paths to Python, .NET, the locally available Godot .NET console, an existing package cache and the original archive root/mount configuration. Output must be a fresh ignored directory inside this repository.

```powershell
& $python .\poc\round86-tests\Integration\run_selected_player.py --dotnet $dotnet --godot $godot --packages $packages --asset-root $assetRoot --config $mountConfig --output $freshOutput --gpu
```

Omit `--gpu` for headless success, cancellation and minimum-provider failure. Run a separate fresh output with `--variant malformed-correction` to reject a truncated first correction after actual login, publication and three movement submissions. No ready or actor is expected for cancellation/provider failure; the malformed correction occurs after one ready and original publication, then closes without publishing a correction.

The independent producer specifies a modern +Z native velocity of two meters per second, three 100000-microsecond steps, flags/counters/timestamp bits and protected sequences. These values are test policy, not recovered original sender timing. Native wire position order remains X,Z,Y; the core model is XYZ and the existing Godot adapter reflects Z. Corrections exercise newer, duplicate, older and wrap-newer counters. Unrelated root, parent and unknown controller kind return owned copies explicitly. Observations contain actual issued motion rows and actual same-instance actor positions; Python compares binary32 values and exact protected datagrams.

The runner stages exact public source bytes, writes their hashes, uses clear-only local package sources, bounds child processes and retains failures. It independently audits installation preparation, loaded dependency identities and original terrain hash. PTAT decoding is the modern minimum provider; complete procedural surface readiness, arbitrary avatar/customization, CREO1/PLAY gameplay and nearby actors remain open. Cleanup drains ports, jobs, actor/presentation, world and owned session buffers. Protocol disconnect/server-observed release remains separate.
