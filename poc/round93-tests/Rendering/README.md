# Round93 standalone offline proof

`replay.py` stages current public production/test sources into a fresh ignored
output, authors fresh accepted protected peers and an original human launch from
explicit installation inputs, then builds/imports Godot using existing bundled
packages. No worker seal, old private vectors or downloaded toolchain is required.

Required absolute-path flags: `--python`, `--dotnet`, `--godot`, `--packages`,
`--asset-root`, `--config`, `--output`. The output must be new and private.
Optional `--gpu` adds one success case through the same mandatory offline seam,
saves the native frame before close/drain/automatic quit, and applies the same
receipt/wire/position/resource/terrain assertions. GPU proof is separately marked.
The Python path is used explicitly for independent producers. Every public source
is hashed before staging and checked again after execution. No public files are
modified by the launcher.

All admitted native executions invoke `ConfigureStandaloneOffline` with an
explicit spy factory, deterministic clock and owned minimum gate. This enters
the same three-argument opt-in admission/application composition as direct CLI.
The source-written real UDP constructor branch is compiled and reviewed, never
invoked. Fake ports independently compare protected bytes and cannot construct
a socket. Source branch shape, mandatory fake substitution, synthetic status/
receipt and actual spy acquisition counts are checked separately.

Twelve standalone cases cover success, missing movement approval, list/readiness
phase stalls, overall stop, successful/faulted delayed startup rollback, send
failure versus cleanup failure, diagnostic collision, pre-ready cancellation and
window close. Each admits the same supported wrong-ID human rejection where the
case reaches selection. Twelve pre-acquisition/owner negatives run inside each
case; success adds a real private junction-parent rejection for thirteen. UNC
paths are rejected lexically without lookup. A missing-movement case reaches
actual original player publication while roots remain disabled. Startup window
close cannot shorten the delayed rollback gate.

The runner verifies actual standalone exit only after the production receipt
reports completed local ownership or rollback. Expected failure cases preserve
the actual native exit code 1 and are labeled `ExpectedOutcomePassed` separately
from command `status`; no failed operation is reported as a successful command.
For a diagnostic collision it checks the sentinel was never overwritten and
the typed final log still distinguishes successful local drain from failed write.

Receipts contain hashes and typed local observations only. Python checks schema
bounds, forbidden identities, phase/overall reasons, root counts, float32 actor
positions/cadence, protected-wire digests and original input/loaded closure/
terrain identities independently. The production minimum callback executes on
real original terrain bytes under owned cancellation. One unchanged injected92
success case proves that API still leaves the caller's quit decision intact.
Four direct-startup cases preserve default refusal and malformed-argument rejection.

Default worker execution is headless. An explicitly requested GPU case proves
bounded original publication and saves its frame. Real UDP construction, live/DNS
contact, physical OS input, complete terrain/floor/validated state, peer identity
and server-observed release are unverified. No original executable is run.
The [bootstrap contract](../../../docs/REPLACEMENT_CLIENT_BOOTSTRAP_CONTRACT.md)
defines the operator prerequisites and stopping condition; further live work
requires specific authorization.
