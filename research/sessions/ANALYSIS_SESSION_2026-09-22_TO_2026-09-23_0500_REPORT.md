## Corrections and uncertainty discipline

- A Ghidra call-convention ambiguity initially made static SROT bytes look like XFIN bytes. Instruction-level disassembly resolved the receiver: XFIN supplies an index into the SROT table. The corresponding checkpoint was corrected.
- SROT disk order is **three selector bytes followed by packed U32**; its expanded in-memory record reverses that layout. A first selector audit sampled the wrong three bytes and falsely claimed all-256 coverage. The corrected corpus uses 127 selector values (128..254) in AROT and 75 of those in SROT. The checkpoint and catalog were corrected.
- An earlier sound outlier was initially suspected to be an extraction error; exact file bytes showed the abnormal value is authored data. This is documented as a bounded anomaly, without claiming a mixer effect.
- `PSKA/0003`, several playback action registrations and some forward asset versions are not automatically client requirements merely because files exist. Reachability must be established before treating them as launch blockers.
