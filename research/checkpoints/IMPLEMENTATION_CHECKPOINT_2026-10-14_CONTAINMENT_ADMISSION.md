## Implementation consequence

An engine-neutral ContainmentGraph::rejectsParent helper uses identity and a supplied parent lookup with Floyd cycle detection. It rejects a known chain reaching the proposed child or already cyclic, uses constant storage, and imposes no arbitrary depth limit. Null/unresolved parents terminate the known chain; late resolution is not claimed fully validated.

ClientObject::updateContainment rejects a nonzero self-parent before snapshot loading or callbacks, and rejects resolved ancestor cycles before changing either parent or slot arrangement. It retains the existing valid relationship and emits only a fixed diagnostic label. Ordinary accepted updates keep their existing callback/arrangement path. This rejects an invalid graph edge; no invented position or substituted parent is returned and NebulaManagerClient is not bypassed.

Object::findPosition_w also checks the exact non-world traversal path for a cycle and fails deterministically if one remains, preserving its existing endpoint position. The lookup adapter stops at an in-world object, matching the original function's stopping condition. This backstop diagnoses unresolved-later/local graph corruption; it is not general scene recovery or proof that all containment writers have admission guards.
