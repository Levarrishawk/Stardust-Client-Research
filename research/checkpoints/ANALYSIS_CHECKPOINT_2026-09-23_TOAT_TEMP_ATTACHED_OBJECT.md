# TOAT temporary attached object action (overnight block 8)

Four `TOAT/0000` nodes occur in two effective scripts: `fire_temp_weapon.pst` and `fire_temp_weapon_particle_system.pst`. Each has one INFO beginning with creation flag 1 and variable tags `NTOW`/`PHPW`, and another INFO beginning with flag 0 and zero tags. `0x005F8C30` installs `TemporaryAttachedObjectActionTemplate`; factory/parser `0x005F8D70`/`0x005F8DD0` accepts `0000`, and `0x005F8F10` reads exactly 12 bytes: one boolean, two 32-bit tags, and three single-byte selector/flag values. The installed template is 0x20 bytes.

Template method `0x005F8CB0` creates a 0x10-byte runtime (`0x005F87C0`, vtable `0x015DF17C`). Runtime method `0x005F88C0` branches on the template boolean. In creation mode it requires a selected actor with `SkeletalAppearance2`, resolves both four-byte tags through the playback string map, uses the object-template name to construct an object (`0x00B288E0`), attaches it as an alternate wearable (`skeletal_attach_alternate_wearable_record_VA_007C9680`), and may bind it back into a playback actor/reference slot through `0x00408210`. `0x005F8AD0` handles the retained object's detach/destroy path using `skeletal_detach_alternate_wearable_record_VA_007C97B0`; the runtime cleanup method `0x005F8AB0` invokes that when it still retains an object. The noncreation branch in `0x005F88C0` resolves selector fields and invokes the same detach helper.

This confirms an original **object-template plus skeletal attachment** dependency for temporary combat weapons. The exact roles of the three one-byte selectors and whether the separate flag-0 action always removes the object created by the flag-1 action are not fully established because Ghidra drops implicit x86 arguments at several helper calls; retain this as a targeted unknown. This is local object lifecycle, not an additional network serialization format.

Provisional names: `0x005F8F10` `parse_TOAT_0000_fields`; `0x005F88C0` `update_TOAT_create_or_remove`; `0x005F8AD0` `detach_TOAT_retained_object`.
