# Analysis checkpoint — CKAT XFIN channel selection and indices

Target: verified `Stardust.exe` and all 7,771 effective `CKAT/0001` clips. Ghidra is reconstructed pseudocode.

Each XFIN record's ten trailing bytes decode by the executable reader `0x00825B30` as U8 animated-rotation flag, U16 rotation index, U8 translation-axis mask, and three U16 translation indices (X/Y/Z). The runtime constructor `0x00822FC0` selects a static or animated rotation evaluator based on the flag. Its translation path reads mask bits **3, 4 and 5**, builds a value 0..7, and dispatches through eight function pointers installed by `0x00822710`. Constructors `0x00823560`–`0x00823A50` call `0x00822200` for unset/static axes and `0x00822290` for set/animated axes. The static route addresses the `STRN` float array (`0x00825570/90/B0`); the animated route addresses the `ATRN` channel array (`0x00825510/30/50`). This establishes the XFIN translation-mask semantics directly, not from naming alone.

Corpus validation covers **298,315** transform records: **171,000** animated-rotation flags and **127,315** static-rotation flags. Every rotation index lies within the corresponding INFO-declared AROT or SROT count; every X/Y/Z index lies within the INFO-declared ATRN or STRN count according to its own mask bit. **Zero out-of-range indices**. The sum of set X/Y/Z mask bits equals the **40,701** deployed ATRN channels, corroborating that each dynamic axis contributes one channel. Only masks `0, 8, 16, 24, 32, 40, 48, 56` occur in the corpus.

This is enough to implement strict structural validation and per-transform channel binding without reverse-engineering the original class layout. Remaining unknown: the exact evaluation/interpolation and quantized translation-value scale.
