## Evidence and findings

1. **Confirmed observation:** `shader/anim_mission_terminal.sht`, priority 38, 475 bytes, SHA-256 `B5AA5A251A76AD8F152DB85F50FBC3061D0494847499F1068A9B55C375785A62`, is SWTS/0000 with NAME `shader/defaultemis.sht`, DTST containing one eight-byte `0000` chunk (`08 00 00 00 CD CC CC 3D`), then eight TEXT references. Each TEXT begins with little-endian MAIN tag `0x4D41494E` and names `_01.dds` through `_08.dds` under `texture/anim_mission_terminal`.
2. **Confirmed observation:** `shader/defaultemis.sht`, priority 38, 171 bytes, SHA-256 `BD33741659BD3C322AE37DC8C0F4DDADBE940502DB273538DB6A34A9FE14D5F7`, is SSHT/0001 with `effect/a_emis_full.eft`, named MAIN TXM /0002 binding and TCSS/0000 metadata. The exact binding bytes and raw DTST fields are recorded in the durable contract.
3. **Strongly inferred interpretation:** matching TEXT/base MAIN tags support explicit selected texture substitution. Modern implementation derives references from the actual base SSHT, retaining base parameters/effect and original SWTS metadata/identity. It creates no artificial SSHT bytes/hash. This interpretation does not establish executable runtime switching or shader fidelity.
4. **Unknown semantics:** DTST word0 coincides with eight references, but a count interpretation remains tentative. Word1 has float32 representation approximately 0.1; its meaning, units, scheduling and initialization role remain unknown. Both words stay raw and are never executed or used to bound the list.
5. **Confirmed replacement result:** frames 0 and 1 independently complete all four original terminal material meshes, retaining vertex counts 208/276/427/496 and triangle counts 102/142/232/296. Each load has 27 sources, 1,401,794 bytes, five distinct material keys, four effects, seven textures and 62 decoded mips. Every source is externally read once, and seven unselected frame DDS files plus replaced `texture/defaulttexture.dds` are absent.
6. **Confirmed original identities:** frame0 DDS SHA `6BA1EC54844D2614DCAF9C37441C7373D63786F2F3B0D43B953F9A0F15BCC938`, mip0 SHA `68761BFA88EEB273A3063B69E228ECAA49E9F6FEAE28CC3C23D567C6B2FC8C70`; frame1 DDS SHA `226A16D33CCFFE97EA9BA07B13F13D4B08C973006FC99C9959C670CCDE382ABD`, mip0 SHA `AD3144AE7FD5B91573B4F7E820D1089DA1027F751CC0BC6FFD6C9D07D591E4FF`. Both are 11,088 bytes at priority34 with eight mips. Independent raw-byte and pixel audits agree.
7. **Confirmed modern policy:** canonical path + exact SWTS SHA + zero-based authored index is required to enable selection. Literal dot/dot-dot segments reject before normalization. Identical SWTS bytes at another shader path stay unselected; a synthetic alias variant in one shared-cache graph keeps three complete meshes and one neutral diagnostic. Ordinary SSHT/EFCT/DDS sharing remains content-based; selected SWTS material derivation bypasses the content-only key.
8. **Confirmed regression:** no option gives the original Round 7 default result, 24 sources / 1,389,982 bytes, two retained material meshes and two SWTS diagnostics; strict loading rejects. Nothing enables automatic switching, frame timing, randomness, callbacks, world readiness or engine rendering.

It initially assumed TXM /0002 for other materials; observed TXM /0001 records required correcting the audit to validate the existing established 11-byte or zero-terminated 12-byte 0001 layout. The corrected audit passes both frames.

Reproduction commands and acceptance limits are in the durable contract. Private evidence and build outputs are ignored; no proprietary asset payload is promoted.
