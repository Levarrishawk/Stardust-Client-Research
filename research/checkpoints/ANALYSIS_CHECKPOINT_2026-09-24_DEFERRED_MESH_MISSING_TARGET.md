The allocator's response, exception boundary, and user-visible outcome remain unknown.

If mesh data exists, the destructor takes the ordinary geometry-release branch. This confirms the intended owner/cancellation pairing for this mesh subtype; it does not make the missing-file parse path safe while the owner is live.
