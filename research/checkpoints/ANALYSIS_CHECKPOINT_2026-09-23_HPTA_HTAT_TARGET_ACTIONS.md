# HPTA hardpoint and HTAT homing-target playback actions (overnight block 14)

Three effective reflect/ricochet scripts contain `HPTA/0000` INFO `00000100544e5048`: two 16-bit actor selectors `0/1` and raw four-byte tag `TNPH`. `HardpointTargetActionTemplate` registers at `0x005FC060`, parser `0x005FC2F0`, factory `0x005FC160`. Runtime `0x005FBBF0` has update `0x005FBB20`. On first update it resolves actor selector 1, resolves the tag `TNPH` as a string via `0x00407D10`, constructs a 0xb0-byte object through `0x00788ED0`/`0x00788F90`, and passes it to `0x00B237C0`; the object is retained in a watcher. It also checks whether actor selector 0 has a `CreatureController` and, when the created object survives, can pass it to that controller through `0x006399D0`. The exact attachment or destination semantics of `0x00B237C0` are not yet established, despite the action name.

One effective script, `fire_projectiles_homing.pst`, contains `HTAT/0000` INFO `454d49544641535446444e4500000100`: three four-byte tags `EMIT`, `FAST`, `FDNE` and actor selectors `0/1`. `HomingTargetActionTemplate` registers at `0x005FB6E0`, parser `0x005FB980`, factory `0x005FB7E0`. Runtime `0x006F9BA0` has update `0x006F9A60`; it creates a 0xb0-byte object through `0x007891E0`/`0x00789220` using a float looked up by `EMIT`, retains it, and each frame calls `0x006F9E90`. The latter obtains both actors' world transforms and positions the object at a weighted interpolation of their positions; it transforms coordinates if the object has a parent. Two further float lookups use `FAST` and `FDNE`; `0x006F9DB0` computes `(FDNE - FAST) / EMIT` with a positive-default fallback. The update modifies the interpolation weight on subsequent ticks and optionally hands the object to a source `CreatureController` via `0x006399D0`.

This is strong evidence for client-side target-marker/projectile choreography, **not** hit authority. The exact time-step formula, float-tag meanings and units, `HPTA` created-object placement, and impact/lifetime boundary are still open. The decompiler's x87 reconstruction around the weight update must not be treated as exact source. Provisional names: `0x005FBB20` `update_HPTA_hardpoint_target`; `0x006F9A60` `update_HTAT_homing_target`; `0x006F9E90` `position_HTAT_object_between_actors`.

Confidence: **confirmed** for versions, field widths, actor/tag lookups, object creation/retention, controller checks, and two-actor weighted position; **tentatively inferred** for the intended homing visual role from names plus geometry; **unknown** for physics/impact semantics.
