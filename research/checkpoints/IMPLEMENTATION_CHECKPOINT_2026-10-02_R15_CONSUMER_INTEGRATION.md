## Observations and consequences

**Observation:** the core consumer owns one bounded adapter dictionary, exact
publication references and creation incarnations. It obtains current snapshots
from the existing world, validates resource attempts and typed state separately,
checks opaque history identity without interpreting it, and records the exact
applied batch object before acknowledgment. Candidate rollback, deferred target
retirement, callback/thread guards, capacity-before-factory, stale retry and
cleanup aggregation have deterministic native coverage. **Confidence:** Confirmed
for modern replacement policy. **Consequence:** engine adapters implement the
small interface; they do not acquire a second registry, state store or loader.

**Observation:** the prototype host factory chooses existing creature/static visuals using
the supplied publication recipe. It checks current metadata/state before allocation
and after attachment, releases the construction snapshot afterward, and owns GPU
retirement. Creature Height/visibility use explicit scalar presentation policy;
static TANO remains opaque. Default switch-texture rejection precedes allocation;
the terminal frame0 inspection override must be explicit. **Confidence:** Confirmed
by source, worker negative/rollback tests and fresh lead standalone headless proof.
**Consequence:** malformed/stale input cannot become an accepted visual, while
state-only updates preserve current resource attempts.

**Observation:** lead joins factory.Create to the core consumer in the existing
mixed preview's optional `--object-consumer` mode. Object IDs are read from exact
47-byte fixture creates; a separately authored peer uses
`0xDABC001122334455` and `0xCABD998877665544`. Initial acceptance is idempotent;
a successfully applied batch becomes stale before acknowledgment; retry applies
the current two-object batch. Destroy/recreate replaces only the terminal; an old
publication rejects. Current family failure retires all consumer actors.
**Confidence:** Confirmed native and prototype host GPU/headless execution. **Consequence:**
the reusable consumer/factory contain no hardcoded preview object IDs; the bounded
proof still selects two explicit original catalog recipes.

**Observation:** original human39/terminal27-source jobs close archives before
transfer. State updates require no new load; terminal recreation raises total
calls from two to three and preserves human incarnation/state/resource/GPU IDs.
The independent six-input image/log oracle reports 14,333 changed human pixels,
unchanged terminal pixels, identical updated/recreated actor regions and matching
GPU/headless poses/state. All three captures were inspected. Real cancellation
enters both open archives, returns zero publications and drains both jobs.
**Confidence:** Confirmed for bounded ownership and diagnostic rendering.
**Consequence:** no full shader, face, animation callback or gameplay fidelity is
inferred from the image comparison.

**Observation:** the independent networking model matches all 40 lifecycle events,
including delayed state, stale completion retirement, foreign ownership despite
matching generation/revision, coalesced acknowledgment and current failure with

resource-attempt freshness cannot substitute for state/incarnation freshness.
