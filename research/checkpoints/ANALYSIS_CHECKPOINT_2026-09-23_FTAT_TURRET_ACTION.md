# FTAT turret playback action (overnight block 13)

The effective overlay has two `FTAT/0000` actions in `fire_turret.pst` and `fire_turret_react.pst`. The former INFO is `00000100ffffffff474d4144`; the latter is `0000010000000100474d4144`. Parser `0x005FCD00` reads four 16-bit values into template `+8/+0xc/+0x10/+0x14`, then four-byte tag `GMAD` into `+0x18`. Thus both assets use actor selectors 0 and 1; the non-react variant has absent target thread/action indices (`ffff/ffff`) and the react variant has target indices `0/1`. The tag is authored raw bytes; its English expansion is not established.

`FireTurretActionTemplate` registers at `0x005FC940` and factory `0x005FCB70`. Its runtime is the common 8-byte `PlaybackScriptAction`-like wrapper from `0x0040ADB0`; template vtable `0x015DF2EC` points to runtime update `0x005FCA20`. That update resolves actor selector 0 and requires `InstallationObject` RTTI. It enumerates installation children (`0x00B23340`/`0x00B23360`) looking for a `TurretObject`, resolves actor selector 1, looks up tag `GMAD` as an integer through `0x00408080`, and passes the target plus a boolean derived from that integer to `0x0061D9C0`. The latter replaces a retained turret target and starts/restarts its firing-related object at `+0xf4` through `0x0060F830`. If both target indices are non-negative, the action also retrieves a particular playback action via `0x004085F0` and retains the produced object there through `0x0040AB20`. Failure to locate the required installation/turret/target marks a byte at playback context `+0x64` before returning.

The strong conclusion is that FTAT drives **client-side turret visual/action state**, with an optional reference handoff to another action. The code shown does not originate a network fire request or prove damage authority. The precise meaning of the integer tag and boolean passed to `0x0061D9C0`, the target action contract, and whether every turret child is searched or only the first matching child need further study. Provisional names: `0x005FCA20` `update_FTAT_turret`; `0x0061D9C0` `turret_set_target_and_restart_visual`; `0x004085F0` `playback_get_action_at_indices`.

Confidence: **confirmed** for binary layout, RTTI checks, child enumeration, integer lookup, retention/handoff mechanics; **strongly inferred** for visual firing interpretation from script and `TurretObject` context; **unknown** for exact gameplay side effects and `GMAD` semantics.
