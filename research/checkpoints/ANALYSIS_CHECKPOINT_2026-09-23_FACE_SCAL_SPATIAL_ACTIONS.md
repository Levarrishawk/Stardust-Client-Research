# FACE and SCAL spatial playback actions (overnight block 11)

`FACE/0001` occurs three times in effective throw scripts; `SCAL/0000` occurs in `change_posture_align.pst` and `restore_scale.pst`. The executable registers `FaceTargetActionTemplate` (`0x005FF420`) and `ChangeScaleActionTemplate` (`0x005FFEE0`). FACE parser `0x005FF770` reads two 16-bit actor selectors plus four four-byte variable tags, matching effective `DPSR`, `HSTA`, `LTTM`, `DRDI`. SCAL parser `0x00600170` reads a 16-bit actor selector, one mode byte, and two four-byte tags, matching effective `LCST`/`EMIT` fields. Their exact tag names are carried as bytes; no English meaning is assumed from spelling.

FACE runtime `0x006FB3E0`/`0x006FB460` resolves source and target actors, requires source `SkeletalAppearance2`, looks up three float controls and optionally passes a fourth float to `CreatureController`. It transforms the target position into source-local coordinates, computes an angle using x87 `fpatan`, limits turning magnitude per frame, updates source orientation through its object virtual method, and decrements an action duration. The decompiled floating-point comparison is convoluted, so exact clamp edge behavior and units should be verified at the instruction level; the **target-facing update loop** is confirmed.

SCAL runtime `0x006FB7F0`/`0x006FB920` requires a `CreatureObject`. It reads the creature's current scale at `+0x734`, requires two float variables, and initializes a scale slope from its mode byte. In mode 0, the slope runs from current scale toward the configured float; in mode 1 it starts from the configured float and runs toward the current scale. Update `0x006FB870` advances elapsed time, computes an interpolated uniform scale, applies it through `0x00B23A10`, and terminates at the duration. The two effective scripts use mode 0 and mode 1 respectively, consistent with change/restore choreography. The exact interpretation of which tag is target versus duration follows the code offset order (`+0x10` target, `+0x14` duration); actual manager binding values still deserve a fixture test.

These are client-side spatial/visual operations. A replacement may redesign transform ownership but must preserve authored target-facing and scale-timing behavior where those playback scripts are used.

Provisional names: `0x006FB460` `update_FACE_target_facing`; `0x006FB920` `initialize_SCAL_creature_scale_transition`; `0x006FB870` `update_SCAL_uniform_scale_transition`.
