RTTI `SwgCuiChatRooms` identifies vtables `0x015F0D78` and `0x015F0CF4`. Constructor `0x00CC8C10` binds `buttonJoin`, `buttonLeave`, `buttonRefresh`, `buttonDone`, `buttonCreate`, `buttonDelete`, `buttonWho`, room-list/tree, slider and room detail text fields. Button callback `0x00CC9230` uses the callback subobject's event source. The selected room is recovered by `0x00CC9AD0` from the current `UIDataSourceContainer` ancestry/full path and looked up in the chat-room manager (`0x00A283A0`); an arbitrary row label is not sent directly as a room ID.
