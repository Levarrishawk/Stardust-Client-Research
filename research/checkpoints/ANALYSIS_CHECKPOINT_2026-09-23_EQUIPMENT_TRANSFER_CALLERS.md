# Equipment transfer caller reconciliation (overnight block 27)

The normal `CuiInventoryManager` equipment helper `0x008D9680` (already described in the inventory-container checkpoint) calls both transfer-family helpers traced in block 26. It obtains the player's named `inventory` slot, resolves the relevant slotted-container arrangement, collects conflicting attached/equipped objects, and for each conflict invokes `0x00654A10` (world/drop with transform) or `0x00654850` (volume/inventory destination) before calling `0x00654720` to insert the requested item into the target slot. Diagnostics distinguish failed removals from failed final insertion. This is a multi-step predicted client-side action, not a single magical equip operation.

`0x009C8E80` is a separate equipment-template restoration path: it fetches a named set of template/arrangement records, instantiates each `ClientObject`, asks for a valid arrangement, then calls the same slotted helper `0x00654720` and logs an equip failure if rejected. `0x0093FCD0` is an IFF cached-inventory reader that reconstructs local `WEAR/ITEM` entries and calls the slotted helper; it is not evidence of live drag/drop. `0x00C887F0` is explicitly gated by an offline/debug flag and populates demonstration inventory templates, so it must not be counted as a production UI interaction.

Cross-boundary interpretation: `CuiInventoryManager` and equipment restore both feed the common transfer helper; in connected mode that helper queues `transferItemArmor`, `transferItemWeapon`, or `transferItemMisc` as documented in block 26. The server subsequently owns actual parent/slot mutation. Predicted client containment must be reconciled with replication and failed commands. The precise mouse/drag event sequence remains open; no UI gesture semantics are invented from these lower-level callers.

Confidence: **confirmed** for direct call edges and diagnostics; **strongly inferred** for the equipment-swap transaction role; **unknown** for the full gesture callback chain and failure/rollback presentation.
